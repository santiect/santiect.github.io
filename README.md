# santiect.github.io

Página acadêmica pessoal — Astro + Tailwind CSS + Markdown, com deploy
automático no GitHub Pages.

Ver [`CLAUDE.md`](./CLAUDE.md) para o guia completo de edição de
conteúdo, paleta de cores, componentes e fluxo de publicação.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
